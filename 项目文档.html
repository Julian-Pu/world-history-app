一、项目概述

1.1 项目背景

历史学习往往枯燥乏味，传统的历史教材以文字为主，缺乏互动性和可视化呈现。本项目旨在打造一个沉浸式、互动式、分级化的世界历史学习平台，通过时间线、地图、人物关系图谱、互动测验等多种形式，让历史学习变得生动有趣。

1.2 项目目标

  • ✅ 覆盖中国史和世界史的核心内容，按教材体系分级
  • ✅ 提供交互式时间线、历史地图、人物关系网络图谱等可视化工具
  • ✅ 支持四级难度分级（幼儿园/小学/初中/高中），适配不同年龄段
  • ✅ 提供学习进度追踪、笔记、收藏、测验、成就系统等学习辅助功能
  • ✅ 支持本地保存与云端同步双模式，用户可自主选择
  • ✅ 响应式设计，适配手机端、平板端、电脑端

1.3 目标用户

用户群体难度等级核心需求
学龄前儿童幼儿园趣味故事、简单概念、图文并茂
小学生小学基础知识、趣味互动、简单测验
初中生初中系统知识、时间线、事件因果
高中生高中深度分析、人物关系、专题研究
历史爱好者全等级拓展阅读、地图探索、关系图谱

二、核心功能（12大模块）

1. 交互式时间线 核心

按时间顺序展示所有历史事件，支持缩放、拖拽、筛选。点击事件节点可查看详情，已读事件有标记。

  • 按时代/地区筛选
  • 事件节点颜色区分时代
  • 已读/未读状态标记
  • 移动端可滑动浏览

2. 事件百科 核心

每个历史事件包含详细的背景、过程、影响、关键人物、相关事件等内容，按四级难度分级呈现。

  • 四级难度内容切换
  • 背景/过程/影响完整结构
  • 关键人物关联
  • 相关事件推荐

3. 人物百科 核心

历史人物详细介绍，包含生平、主要成就、历史评价等，支持按朝代/地区筛选。

  • 人物详情页
  • 按朝代/地区筛选
  • 人物关系关联
  • 相关事件推荐

4. 人物关系网络图谱 新增

使用 ECharts 力导向图展示历史人物之间的关系网络，支持按朝代筛选、点击查看详情、缩放拖拽。

  • 力导向图自动布局
  • 15种关系类型（君臣/师生/对手/政敌/父子等）
  • 按朝代筛选
  • 点击节点查看人物详情和关系列表
  • 支持缩放、拖拽、漫游

5. 历史地图

历史地图展示，支持按时代切换，直观展示不同历史时期的疆域、政权分布。

  • 按时代切换地图
  • 疆域/政权标注
  • 重要地点标记

6. 互动测验

按难度分级的历史知识测验，包含选择题，完成后显示得分和答案解析。

  • 四级难度题库
  • 选择题型
  • 即时评分和解析
  • 测验记录保存
  • 错题本功能

7. 学习笔记 核心

支持在事件/人物详情页添加笔记，使用 Tiptap 3 富文本编辑器，支持文字、列表、链接等格式。

  • Tiptap 3 富文本编辑器
  • 按事件/人物关联笔记
  • 笔记列表管理
  • 搜索和筛选

8. 收藏功能

收藏感兴趣的事件和人物，方便后续复习和查阅。

  • 事件/人物收藏
  • 收藏列表管理
  • 按类型筛选

9. 学习进度追踪 核心

自动追踪学习进度，包括已读事件/人物、学习时长、连续学习天数、时代完成度等。

  • 已读事件/人物统计
  • 学习时长自动计时
  • 连续学习天数（打卡）
  • 时代完成度进度条
  • 学习日历热力图

10. 成就系统

根据学习行为解锁各种成就徽章，激励用户持续学习。

  • 多种成就徽章
  • 解锁条件追踪
  • 成就展示墙

11. 双模式存储 新增

支持本地保存和云端同步两种模式，用户可在设置中自主选择。云端模式下数据自动同步，支持多设备访问。

  • 本地模式：数据保存在浏览器 localStorage
  • 云端模式：数据同步到服务器，支持多设备
  • 手动同步按钮
  • 数据导入/导出功能
  • 按类型清除数据（本地/云端）

12. 搜索功能

全局搜索历史事件和人物，支持关键词模糊匹配。

  • 事件/人物全局搜索
  • 关键词高亮
  • 搜索历史记录

六、内容分级体系

6.1 四级难度

等级目标年龄内容特点语言风格
幼儿园3-6岁简单故事、趣味插图、基础概念口语化、拟人化、短句
小学7-12岁基础知识、时间地点人物、简单因果通俗易懂、生动有趣
初中13-15岁系统知识、事件背景、影响分析规范严谨、逻辑清晰
高中16-18岁深度分析、多角度评价、专题研究学术化、思辨性

6.2 内容结构（每个事件）

  • summary：内容摘要
  • background：历史背景
  • process：事件过程
  • impact：历史影响
  • funFacts：趣味知识（低等级）
  • keyFigures：关键人物
  • relatedEventIds：相关事件

七、部署快速指南

7.1 环境要求

项目要求说明
Node.js>= 22.0.0前端构建需要，后端建议同版本
npm>= 10.0.0随 Node.js 安装
操作系统Windows / macOS / Linux跨平台支持
内存>= 4GB前端构建建议 8GB
⚠️ 重要：前端项目要求 Node.js >= 22，如果系统版本较低，建议使用便携版 Node，不修改系统环境变量。便携版路径：E:\ProgramData\historyApp\node-v22\

7.2 快速启动（Windows）

  1. 双击项目根目录下的 启动服务.bat
  2. 等待后端服务启动（约3-5秒）
  3. 浏览器访问 http://localhost:3000
  4. 默认管理员账号：admin@history.com / admin123456

7.3 手动部署步骤

后端部署

cd backend
npm install
node server.js

前端构建

cd front
npm install --ignore-scripts
$env:NODE_ENV="production"
node node_modules/vite/bin/vite.js build --config vite.config.ts
💡 Windows 构建注意：不能使用 npm run build:client（Unix 语法在 Windows 报错），必须使用上述命令手动构建。构建后需要替换 index.html 中的11个平台模板变量。

7.4 手机端访问

  1. 确保手机和电脑在同一局域网
  2. 查看电脑局域网 IP（如 192.168.2.5）
  3. 手机浏览器访问 http://192.168.2.5:3000
